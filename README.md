# DanaPanel 🎓

A Student Management System — a simple, attractive, and professional dashboard for managing students, courses, and academic information.

## About

DanaPanel is a front-end project built to manage and display student data through a modern dashboard interface. The project consists of 5 main pages.

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Pages

- [ ] Dashboard (Overview)
- [ ] Students List
- [ ] Courses
- [ ] Profile
- [ ] Settings

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/adela-ahmadi/DanaPanel.git
   ```
2. Navigate into the project folder:
   ```bash
   cd DanaPanel
   ```
3. Open `index.html` in your browser.
